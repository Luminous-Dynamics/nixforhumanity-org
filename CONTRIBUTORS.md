## 📝 How to Contribute

### Getting Started

1. **Read the docs:**
   - [CONTRIBUTING.md](CONTRIBUTING.md) - Contribution guidelines
   - [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) - Community standards
   - [README.md](README.md) - Project overview

2. **Find an issue:**
   - Look for [`good first issue`](https://github.com/Luminous-Dynamics/nixforhumanity-org/labels/good%20first%20issue)
   - Check [`help wanted`](https://github.com/Luminous-Dynamics/nixforhumanity-org/labels/help%20wanted)
   - Or propose your own!

3. **Make your contribution:**
   - Fork the repository
   - Create a branch
   - Make your changes
   - Test thoroughly
   - Submit a PR

4. **Get recognized:**
   - Your name added here
   - Mentioned in release notes
   - Community appreciation!
