NixOS for Humans

Just speak naturally. We handle the complexity.

$ ask-nix "install a web browser"
🔍 Understanding your request...
📦 Found: firefox, chromium, brave
💡 Recommending: firefox (most popular, open-source)

Would you like to install firefox? [Y/n]
$ Y
✨ Installing firefox...
✅ Successfully installed! Run 'firefox' to start.
$

No more cryptic commands. No more configuration files. Just natural language that works.
