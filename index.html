Why Luminous Nix?

Compare traditional NixOS package management with our natural language approach

Traditional NixOS
Luminous Nix
Install Firefox
nix-env -iA nixpkgs.firefox ⚠️ Must know exact package name
ask-nix "install a web browser" ✅ Natural language
Search Packages
nix search nixpkgs firefox ⏱️ 2-5 seconds (timeouts common)
ask-nix "find firefox" ⚡ 0.29ms (10,000x faster)
Setup Dev Environment
Write configuration.nix:
environment.systemPackages = with pkgs; [ rustc cargo rust-analyzer ]; ⚠️ Manual configuration editing
ask-nix "set up rust development" ✅ One command, AI handles it
Rollback
nix-env --rollback ⚠️ Must remember command
ask-nix "undo that" ✅ Conversational rollback
Accessibility

Voice control, screen readers, simple language ♿ Built for everyone
